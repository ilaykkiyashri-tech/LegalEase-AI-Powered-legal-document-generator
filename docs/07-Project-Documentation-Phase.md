# Phase 7: Project Documentation

## Project Overview
**LegalEase** is an AI-powered legal document generator that uses Google's Gemini model to produce customizable, editable legal documents (employment contracts, NDAs, lease agreements, and more) from simple structured inputs, with export to .TXT, .DOCX, and .PDF.

## Setup / Installation Guide
1. **Install Python 3.10+** and ensure `pip` is available.
2. **Create and activate a virtual environment:**
   ```
   python -m venv venv
   venv\scripts\activate   # Windows
   ```
3. **Install dependencies:**
   ```
   pip install -r requirements.txt
   ```
   (or individually: `pip install fastapi uvicorn streamlit python-docx fpdf Pillow requests google-generativeai python-dotenv`)
4. **Configure environment variables:** create a `.env` file with:
   ```
   GEMINI_API_KEY=your_api_key_here
   ```
5. **Run the backend:**
   ```
   uvicorn legalEaseAPI.main:app --reload
   ```
6. **Run the frontend (in a separate terminal):**
   ```
   streamlit run frontend/app.py
   ```
7. Open `http://localhost:8501` in your browser.

## User Guide

### Inputs
| Field | Purpose | Example |
|-------|---------|---------|
| Document Type | Type of legal document to generate | `Freelance Work Contract` |
| Parties Involved | Names/roles of individuals or entities | `Jane Doe (Service Provider), TechNova Inc. (Client)` |
| Terms & Conditions | Clauses, semicolon-separated | `Payment within 30 days of invoice; Confidentiality must be maintained at all times` |
| Effective Date | Date the agreement becomes valid | `April 15, 2025` |

### Workflow
1. Fill in the four input fields.
2. Click **Generate Document** — content is generated by Gemini and shown in a styled preview.
3. Click **Click to Edit Document** to revise the text inline if needed.
4. Download the final document as **.TXT**, **.DOCX**, or **.PDF**.

## API Reference
**`POST /generate`**
- Request body: `{ "document_type": str, "parties": str, "terms": str, "dates": str }`
- Response: `{ "document": "<generated text>" }`

## Core Function Reference
| Function | Purpose |
|----------|---------|
| `sanitize_text(text)` | Cleans special characters/typographic quotes |
| `format_docx(text, doc_type)` | Produces a branded Word document with a terms table |
| `format_pdf(text, doc_type)` | Produces a branded PDF with header/footer |
| `format_html_preview(text)` | Renders styled HTML for the in-app preview |

## Known Limitations / Future Enhancements
- No legal-validity review — generated content should be checked by a qualified professional before formal use
- No e-signature integration
- Currently local-only deployment (cloud deployment is a planned next step: Render, Railway, Fly.io, or a VPS for the backend; Streamlit Community Cloud for the frontend)
- Multilingual document generation not yet implemented
